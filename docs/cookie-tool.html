🔑 Cookie Capture Tool

For GoMining ServiceTap — grabs the login ServiceTap needs with one click, no digging through DevTools. Using the setup wizard? It has this built in — you don't need this page. This page is for re-capturing a login later, or for setting things up by hand.

Step 1 — Get the tool

📋 Capture GoMining Cookies

Drag that button up to your browser's bookmarks bar (one time). On phones/tablets bookmarklets generally don't work — see the manual method in the repo's README.

Step 2 — Use it

Tip — use a private window. GoMining changes your login every time it's used, so if the automation and your everyday browser share one login, they can knock each other out. Open a private/incognito window, do the steps below there, then simply close the window. (Don't click "Log out" first — that may end the session you just captured.)

  1. Log into app.gomining.com (in that private window).
  2. Click the bookmark you just saved. A green note appears on the page: Copied!
  3. That's it — the login is on your clipboard, ready to paste.
If setup later fails with a Cloudflare error

This tool copies two cookies: access_token and refresh_token. A third, cf_clearance, belongs to Cloudflare and can't be read by any webpage. ServiceTap's browser is normally issued its own automatically — verified from a GitHub Actions runner — so it isn't needed. If a run ever reports a Cloudflare block, open DevTools (F12) → Application → Storage → Cookies → https://app.gomining.com, and add one more entry to the pasted list: {"name":"cf_clearance","value":"…","domain":".gomining.com","path":"/","httpOnly":true,"secure":true,"sameSite":"None"}.

Step 3 — Paste it into GitHub

In your copy of the repo: Settings → Secrets and variables → Actions → New repository secret. Name it GOMINING_COOKIES_<LABEL> (e.g. GOMINING_COOKIES_PRIMARY) and paste what you copied as the value.

⚠️ This is a login session for your account, not your password — but treat it the same as you would a "stay signed in" cookie: don't paste it anywhere except a GitHub Secret (which nobody, including GitHub, can read back once saved), and never share it or paste it into a chat, doc, or issue.

Runs entirely in your own browser — nothing here is sent anywhere except your own clipboard.
