🔑 Cookie Capture Tool

For GoMining ServiceTap — grabs the three values ServiceTap needs, without you hunting through DevTools by hand for all of them.

Step 1 — Get the tool

📋 Capture GoMining Cookies

Drag that button up to your browser's bookmarks bar. (On phones/tablets, bookmarklets generally don't work — use the manual DevTools method in the repo's README instead.)

Step 2 — Use it

  1. Log into app.gomining.com normally, same as always.
  2. Click the bookmarklet you just saved. It reads two of the three values it needs automatically.
  3. It'll ask you for one more value it can't read itself (cf_clearance — a Cloudflare security cookie, deliberately locked down). Open DevTools (F12, or Cmd+Opt+I on Mac) → Application tab → Storage → Cookies → https://app.gomining.com, find the row named cf_clearance, and paste its Value column into the box the bookmarklet showed you.
  4. It copies the finished result to your clipboard (or shows it in a box to copy if your browser blocks that) — ready to paste straight into GitHub.

Step 3 — Paste it into GitHub

In your copy of the repo: Settings → Secrets and variables → Actions → New repository secret. Name it GOMINING_COOKIES_<LABEL> (e.g. GOMINING_COOKIES_PRIMARY) and paste what you copied as the value.

⚠️ This is a login session for your account, not your password — but treat it the same as you would a "stay signed in" cookie: don't paste it anywhere except a GitHub Secret (which nobody, including GitHub, can read back once saved), and never share it or paste it into a chat, doc, or issue.

Runs entirely in your own browser — nothing here is sent anywhere except your own clipboard.
